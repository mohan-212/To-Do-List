# To-Do-Lists App

A simple and beautiful app to manage your daily tasks with sticky notes and multiple views.

## 🚀 Quick Start

1. **Open** `index.html` in Chrome browser
2. **Login** with:
   - Username: `mohan` 
   - Password: `password123`
3. **Start adding tasks!**

## 📋 What Can You Do?

### Add a Task
- Click "+ Add New Task"
- Type your task name
- Done!

### View Your Tasks
- **Sticky Wall** - See all tasks as colorful sticky notes (default home view)
- **Today** - Only tasks for today
- **Upcoming** - Tasks coming up
- **Personal/Work** - Filter by category

### Edit a Task
- Click on any task
- Right panel opens with details
- Change: Title, Description, Due Date, Category
- Click "Save changes"

### Complete a Task
- Click the checkbox ✓
- Task gets checked off

### Delete a Task
- Select a task
- Click "Delete Task"

### Sign Out
- Click "🚪 Sign out" at bottom left
- Back to login screen

## 💾 Your Tasks Save Automatically

- Tasks are saved to your browser
- Close the app and come back - they're still there!
- No login required for storage

## 🎨 Cool Features

- **Sticky Notes View** - Your tasks look like notes on a wall
- **Multiple Colors** - Each task gets a unique color
- **Fast & Smooth** - Super quick interactions
- **Works Offline** - No internet needed
