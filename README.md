# To-Do-Lists App 📝

A modern, fast web app to manage tasks with sticky notes and user authentication.

## 🎯 Purpose
Organize tasks visually with a beautiful sticky wall interface. Track personal and work tasks, set due dates, and keep everything in sync automatically.

## ✨ Features
- 🔐 **User Login** - Secure authentication with credentials
- 📌 **Sticky Wall** - Colorful sticky notes on wall (default home view)
- 📅 **Multiple Views** - Today, Upcoming, Personal, Work filters
- 💾 **Auto-Save** - Tasks save automatically to browser
- ⚡ **Fast & Smooth** - Optimized with GPU acceleration
- 📱 **Responsive** - Works on desktop and mobile

## 🚀 Quick Start
1. Open `index.html` in Chrome
2. Login: `mohan` / `password123`
3. Click "+ Add New Task" and start organizing!

## 📖 How to Use
| Action | Steps |
|--------|-------|
| Add Task | Click "+ Add New Task" → Type title |
| Edit Task | Click task → Modify details → Save |
| Complete | Click checkbox ✓ |
| Delete | Select task → "Delete Task" |
| Change View | Use sidebar buttons |
| Logout | Click "🚪 Sign out" |
